# Review notes

For local work, inspect staged, unstaged and untracked files. For an explicit commit review, inspect that range. Compare pre-existing edits against the task's starting context. See [shared guidance](../../AI_WORKFLOW.md).

An optional review brief:

- Goal and scope
- Relevant changes and existing user edits
- Checks performed and remaining uncertainty

An actionable finding states **location, trigger, impact and evidence**. Prioritize correctness and regressions, and distinguish confirmed defects from assumptions. During implementation, fix confirmed issues within scope; a standalone review returns findings without applying unrequested changes.

Finish with the result and validation limits. Use a formal checklist or finding log only when it helps the task.
