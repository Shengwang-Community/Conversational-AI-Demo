description: Use when a long Android task would benefit from a checkpoint or recovery note.
---

Keep a short optional note under Android `.agents/state/` with the goal, decisions, actual checks and next step. Read existing notes when useful for continue, and verify them against current code.

Preserve historical records. Use any clear format; no index or legacy state fields are required. Simple tasks and read-only reviews can proceed directly.
