name: requesting-code-review
description: Use when preparing Android changes for a useful review.
---

Provide the goal, relevant changes, existing user edits and actual checks. Use [the review brief](code-reviewer.md) if helpful. Review current files, including untracked additions for local work.

Choose a review method appropriate to the task and available permissions. No commit, task-state file or formal handoff is needed to review local changes.
