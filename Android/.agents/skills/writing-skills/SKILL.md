name: writing-skills
description: Use when creating or simplifying repository skills and AI guidance.
---

Keep guidance short, specific to the project and in English. Put shared advice in root `AI_WORKFLOW.md`; skills should add useful context rather than repeat a process.

Prefer optional tools and examples over mandatory stages, scores, state schemas or retry limits. Check triggers, references and examples against actual use. For scripts, exercise relevant success and failure behavior; for docs, check wording, paths and consistency.

Older methodology references in this directory are optional background, not additional requirements or required reading.
