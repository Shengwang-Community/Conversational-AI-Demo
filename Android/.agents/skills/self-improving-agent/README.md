# Reusable lessons

Use [the skill](SKILL.md) when a retrospective or repeated issue yields a useful lesson. It is optional and independent of any task-state or review sequence.

Base advice on the conversation, code and actual checks. Keep only lessons with clear evidence and applicability. Apply relevant guidance improvements within the user's authorized scope, or describe a suggested follow-up.

Existing `memory/` files and [templates](templates/pattern-template.md) are optional aids. Keep historical records intact and avoid adding bookkeeping that costs more than the lesson saves.
