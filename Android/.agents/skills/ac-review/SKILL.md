name: ac-review
description: Use when reviewing Android changes for correctness, regressions and validation gaps.
---

Review the requested scope against current code. Local review includes staged, unstaged and untracked files; a commit review uses the requested range. Preserve the distinction between existing user edits and new work.

Prioritize actionable findings with location, trigger, impact and evidence. Report actual checks and uncertainty. During implementation, resolve confirmed issues within scope; a standalone review returns findings without unrequested edits or state bookkeeping.
